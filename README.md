# belajar-github

Repository latihan issue, branch, dan pull request GitHub.

## Tujuan

- Memahami cara mencatat pekerjaan melalui issue.
- Membuat perubahan kecil di branch terpisah.
- Mengirim pull request (PR) dan menggabungkannya ke branch `main`.

## Istilah Dasar

| Istilah | Arti |
| --- | --- |
| Repository | Tempat menyimpan file dan riwayat perubahan proyek. |
| Issue | Catatan tugas, pertanyaan, atau laporan masalah. |
| Branch | Jalur kerja terpisah untuk menyiapkan perubahan. |
| Commit | Rekaman perubahan dengan pesan penjelasan. |
| Pull request | Usulan perubahan dari sebuah branch ke branch lain. |
| Merge | Menggabungkan perubahan ke branch tujuan. |

## Latihan Melalui Website GitHub

1. Buat issue yang menjelaskan perubahan yang ingin dikerjakan.
2. Buka file yang ingin diperbaiki, lalu pilih tombol edit.
3. Lakukan perubahan kecil dan tulis pesan commit yang jelas.
4. Pilih opsi membuat branch baru dan membuka pull request.
5. Periksa tab **Files changed** untuk memastikan perubahan sesuai tujuan.
6. Jika perubahan sudah benar dan aturan repository terpenuhi, merge PR.
7. Tutup issue yang selesai dan hapus branch latihan yang tidak diperlukan.

## Kebiasaan Baik

Untuk latihan melalui terminal, baca [panduan kontribusi](CONTRIBUTING.md).

- Jangan mengunggah password, token, atau data pribadi.
- Buat satu PR untuk satu tujuan agar mudah diperiksa.
- Ikuti aturan review saat berkontribusi ke proyek lain.
- Gunakan repository sendiri untuk latihan, bukan membuat spam di proyek orang lain.

## Tentang Achievement

Achievement adalah bonus dari aktivitas GitHub, bukan tujuan utama proyek ini.
Pemberian dan waktu tampil lencana ditentukan oleh GitHub; menyelesaikan latihan
tidak menjamin lencana langsung muncul.
